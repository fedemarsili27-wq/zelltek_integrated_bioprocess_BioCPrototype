# zelltek_integrated_bioprocess_BioCPrototype

## Descripción del Sistema
Diseño conceptual de un sistema de software para integrar y automatizar las etapas upstream y downstream de un proceso biotecnológico continuo (cultivo de células CHO en perfusión, cosecha continua con la etapa de purificación integrada).

## Objetivo Principal
Integrar y sincronizar las variables de upstream y downstream, calculando y transmitiendo consignas automáticas a los controladores.

## Alcance Funcional
- Recepción y almacenamiento de variables de proceso correspondientes a las etapas de cultivo y purificación.
- Correlación y evaluación de compatibilidad entre caudal de cosecha y capacidad de downstream.
- Generación y transmisión de consignas para ajustar, mantener o detener al proceso global.
